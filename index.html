PraxisWhat, not how.

A discipline framework for AI coding agents. Tell your agent what you need and what done looks like — not how to do it.

Get Started
View on GitHub

Triage-driven

Every task is classified by scope before any skill loads. Trivial tasks skip the waterfall entirely — no ceremony unless it pays back.

Token-lean

Skills average ~230 tokens each. A full design→ship cycle costs ~1,300 tokens. Compare to alternatives at 30–50k.

Intent, not instruction

Specs are lists of decisions. Plans are milestone stubs. The agent brings domain knowledge — Praxis provides what matters.

Cross-harness

Works with Claude Code, Codex, OpenCode, GitHub Copilot CLI, and any harness that can read a markdown file.

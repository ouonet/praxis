# Grok host + package metadata

purpose: Make Praxis a first-class Grok host: skills install AND session-start injection of using-praxis (via Grok rules, not SessionStart hook). Fill npm package identity (homepage, license/copyright).

## contract

### Grok host
- `HOSTS.grok`: id `grok`; aliases `grok-cli`, `xai-grok`; displayName `Grok CLI`; `cliBinary` `grok`.
- Scopes: `user` → `~/.grok/plugins/praxis`; `project`/`local` → `.grok/plugins/praxis`.
- `nativeInstallCmd` / `nativeUninstallCmd` / `nativeUpdateCmd`: `null`. File install is the source of truth (Grok SessionStart stdout is discarded; native plugin install does not load `rules/`).
- `npx @ouonet/praxis install --host grok` (and `--host all` when `grok` is on PATH) uses file install.

### Bootstrap (using-praxis auto-intro)
Grok auto-loads `*.md` from `$GROK_HOME/rules/` and `<repo>/.grok/rules/` into session context. Installer MUST copy `rules/praxis.md` (using-praxis triage body) there.

| scope | plugin | skills | rules |
| ----- | ------ | ------ | ----- |
| user | `~/.grok/plugins/praxis` | `~/.grok/skills` | `~/.grok/rules/praxis.md` |
| project / local | `<root>/.grok/plugins/praxis` | `<root>/.grok/skills` | `<root>/.grok/rules/praxis.md` |

Plugin dir is auto-trusted at `~/.grok/plugins/`; project `.grok/plugins/` still requires Grok folder trust. Standalone skills + rules load without `[plugins].enabled`.

Installer does **not** edit `config.toml` (`[plugins].enabled`).

### Uninstall
Remove only Praxis-owned paths: plugin dir `praxis`, `PRAXIS_SKILL_NAMES` under the skills dir, `praxis.md` under the rules dir. Preserve other `.grok/` files (custom rules, MCP, user config). Missing paths are skips.

### Status
- `userInstalled` if plugin dir, `~/.grok/rules/praxis.md`, `~/.grok/skills/using-praxis`, or `~/.grok/installed-plugins/registry.json` names plugin `praxis`.
- `projectInstalled` / `localInstalled` if `.grok/plugins/praxis` or `.grok/rules/praxis.md` or `.grok/skills/using-praxis`.

### Marketplace index
`.grok-plugin/marketplace.json` exists; plugin version matches `package.json`. Grok also accepts `.claude-plugin/`; the Grok-native index is required so `grok plugin marketplace add ouonet/praxis` is first-class.

### package.json identity
Required fields:
- `description`: same as root `plugin.json` description
- `license`: `MIT` (SPDX; copyright text remains `LICENSE`: Copyright (c) 2026 Praxis contributors)
- `author`: `ouonet`
- `homepage`: `https://ouonet.github.io/praxis/`
- `repository`: `{ "type": "git", "url": "git+https://github.com/ouonet/praxis.git" }`
- `bugs`: `{ "url": "https://github.com/ouonet/praxis/issues" }`

### Public CLI surface
`--host grok` listed in help. Supported-hosts contract includes `grok`.

### Native (docs only, not installer)
```
grok plugin marketplace add ouonet/praxis
grok plugin install praxis --trust
```
Native install is optional extra for the plugin catalog; it does **not** replace rules copy. README must say rules (or Praxis CLI) are required for using-praxis auto-intro.

## invariant
- Grok session bootstrap is `rules/praxis.md`, never SessionStart `additionalContext`.
- File install works when `grok` binary is absent (`method: file`).
- Uninstall never deletes non-Praxis rules or whole `~/.grok`.
- Manifest versions (including `.grok-plugin/marketplace.json`) match `package.json`.

## failure
- Source `rules/` missing → `copyPraxisRulesToDir` no-ops (existing).
- Native Grok plugin without rules → triage not injected (documented; CLI install always copies rules).
- Project plugin hooks/MCP stay inactive until folder trust; rules and `.grok/skills` still load.

## out of scope
- Teaching Grok to honor SessionStart `additionalContext`
- Auto-writing `[plugins].enabled` in TOML
- Changing `rules/praxis.md` triage table
- Releasing a new version number (CHANGELOG Unreleased only)

## test
- `resolveHost('grok'|'grok-cli'|'xai-grok')` → `grok`
- `installHost(HOSTS.grok, { scope: 'project', method: 'file', rootDir: tmp })` creates plugin skills, `.grok/skills/using-praxis/SKILL.md`, `.grok/rules/praxis.md`
- uninstall removes those three; leaves `.grok/rules/custom.md`
- `package.json` has `license === 'MIT'`, `homepage`, `repository.url`, `bugs.url`
- `invariants`: `.grok-plugin/marketplace.json` version matches; `HOSTS` includes `grok`

## convention
- Follow existing antigravity host adapter: file-first, `copyPraxisSkillsToDir` + `copyPraxisRulesToDir` + `copyPluginFiles`, non-destructive uninstall.
- Tests: `node:test` + `assert/strict`; project-scope in `os.tmpdir()` only (do not write user-scope into the real `~/.grok` in tests).
- Docs: tech-spec `entry`/`contract`/`constraint` SessionStart policy; README + site en/zh getting-started; CHANGELOG Unreleased.
- No new runtime dependencies (no TOML parser).

# 技能

技能是注入结构化规范的短 markdown 文件。每个技能仅在需要其范围时加载。

| 技能 | 何时用 | Token |
|---|---|---|
| [design](./design) | 范围 ≥ standard，任何新工作；目标模糊时先澄清再设计 | ~250 |
| [plan](./plan) | 设计获批后 | ~200 |
| [tdd](./tdd) | 实现或修复 | ~400 |
| [debug](./debug) | 出问题了 | ~150 |
| [review](./review) | 合并前 / subagent 任务后 | ~150 |
| [worktree](./worktree) | 非平凡或并行工作 | ~150 |
| [subagents](./subagents) | 独立任务、fan-out | ~150 |
| [ship](./ship) | 合并 / PR / 清理 | ~100 |
| [archive](./archive) | 合并规范至现存文档并清理暂存区 | ~150 |
| [release](./release) | 版本 / tag / 发布 | ~150 |
| [onboard](./onboard) | 现有项目，无技术规范 | ~200 |

## 共享协议与参考规范

- [质量标准](./quality)：机械化检查、约定遵循、设计评估及文档覆盖率标准。
- [规范评审员](./reviewers)：并行规范评审员的触发匹配表与审查职责。
- [多模块协议](./multi-module)：跨仓库与多模块变更的拓扑规范。

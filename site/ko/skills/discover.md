# discover → design

::: info design에 통합되었습니다
`discover` 스킬은 [`design`](./design)에 통합되었습니다.

목표가 모호한 경우 `design`을 로드합니다. 문제가 명세화할 수 있을 만큼 구체적이 될 때까지 한 번에 하나씩 명확화 질문을 합니다. 작업 노트에 가설과 실험을 기록할 수 있으며, 빌드 결정 없이 탐색이 끝나는 경우의 명시적인 중단 경로도 있습니다.

지식형 산출물(프로토콜 명세, 리버스 엔지니어링 발견, 데이터 구조 맵)은 `archive`를 통해 `docs/decisions/`에 저장됩니다.
:::

# 스킬

스킬은 에이전트 세션에 구조화된 규율을 주입하는 짧은 Markdown 파일입니다. 각 스킬은 해당 스코프가 필요할 때만 로드됩니다.

| 스킬 | 사용 시점 | 토큰 수 |
|---|---|---|
| [design](./design) | 스코프 ≥ standard, 새로운 작업. 모호한 목표 명확화 및 명세 리뷰어 | ~1,180 |
| [plan](./plan) | 설계 승인 후. 마일스톤 및 작업 분할 | ~740 |
| [tdd](./tdd) | 구현 또는 수정 시. 3차원 품질 리팩토링 게이트 | ~590 |
| [debug](./debug) | 문제가 발생했을 때. 근본 원인 격리 | ~160 |
| [review](./review) | 병합 전 / 서브에이전트 작업 후. 표준 및 문서 검증 | ~420 |
| [worktree](./worktree) | 병렬 작업 또는 독립된 작업. Git worktree 격리 | ~320 |
| [subagents](./subagents) | 독립적인 작업 팬아웃. 역할 계약 및 모델 계층 | ~1,020 |
| [ship](./ship) | 병합 / PR / 정리 | ~430 |
| [archive](./archive) | 명세서를 라이빙 문서로 병합 및 정리 | ~730 |
| [release](./release) | 버전 / 태그 / 배포 | ~220 |
| [onboard](./onboard) | 기존 프로젝트(기술 명세 없음) | ~450 |

## 공유 프로토콜 및 참조

- [품질 표준](./quality) (약 ~430 토큰): 기계적 검사, 관례 준수, 설계 평가 및 문서 커버리지 규칙.
- [명세 리뷰어](./reviewers) (약 ~1,640 토큰): 병렬 명세 리뷰어 트리거 표 및 역할 정의.
- [멀티 모듈 프로토콜](./multi-module) (약 ~870 토큰): 다중 리포지토리/모듈 변경을 위한 토폴로지 사양.

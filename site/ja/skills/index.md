# スキル

スキルは、エージェントセッションに構造化された規律を注入する短い Markdown ファイルです。各スキルは、そのスコープが必要とされたときのみロードされます。

| スキル | 用途 | トークン数 |
|---|---|---|
| [design](./design) | スコープ ≥ standard、新規作業。曖昧な目標は設計前に明確化 | ~250 |
| [plan](./plan) | 設計の承認後 | ~200 |
| [tdd](./tdd) | 実装または修正 | ~400 |
| [debug](./debug) | 問題のデバッグ | ~150 |
| [review](./review) | マージ前 / サブエージェントタスク後 | ~150 |
| [worktree](./worktree) | 並行作業または独立した作業 | ~150 |
| [subagents](./subagents) | 独立したタスクのファンアウト | ~150 |
| [ship](./ship) | マージ / PR / クリーンアップ | ~100 |
| [archive](./archive) | 仕様書をリビングドキュメントに統合・クリーンアップ | ~150 |
| [release](./release) | バージョン / タグ / リリース | ~150 |
| [onboard](./onboard) | 既存プロジェクト（技術仕様書なし） | ~200 |

## 共有プロトコルとリファレンス

- [品質標準](./quality): メカニカルチェック、規約遵守、設計評価、ドキュメントカバレッジルール。
- [仕様レビュアー](./reviewers): 並行仕様レビュアーのトリガー表と役割定義。
- [マルチモジュールプロトコル](./multi-module): 複数リポジトリ・モジュール変更のためのトポロジー仕様。

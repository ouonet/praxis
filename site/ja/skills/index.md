# スキル

スキルは、エージェントセッションに構造化された規律を注入する短い Markdown ファイルです。各スキルは、そのスコープが必要とされたときのみロードされます。

| スキル | 用途 | トークン数 |
|---|---|---|
| [design](./design) | スコープ ≥ standard、新規作業。曖昧な目標の明確化 & トリガー型レビュアー | ~1,180 |
| [plan](./plan) | 設計承認後。マイルストーンとタスク分解 | ~740 |
| [tdd](./tdd) | 実装または修正。3次元品質リファクタゲート | ~590 |
| [debug](./debug) | 問題のデバッグ。根本原因の特定 | ~160 |
| [review](./review) | マージ前 / サブエージェントタスク後。標準 & ドキュメント検証 | ~420 |
| [worktree](./worktree) | 並行作業または独立した作業。Git worktree 隔離 | ~320 |
| [subagents](./subagents) | 独立したタスクのファンアウト。役割契約 & モデル階層 | ~1,020 |
| [ship](./ship) | マージ / PR / クリーンアップ | ~430 |
| [archive](./archive) | 仕様書をリビングドキュメントに統合・クリーンアップ | ~730 |
| [release](./release) | バージョン / タグ / リリース | ~220 |
| [onboard](./onboard) | 既存プロジェクト（技術仕様書なし） | ~450 |

## 共有プロトコルとリファレンス

- [品質標準](./quality)（約 ~430 トークン）: メカニカルチェック、規約遵守、設計評価、ドキュメントカバレッジルール。
- [仕様レビュアー](./reviewers)（約 ~1,640 トークン）: 並行仕様レビュアーのトリガー表と役割定義。
- [マルチモジュールプロトコル](./multi-module)（約 ~870 トークン）: 複数リポジトリ・モジュール変更のためのトポロジー仕様。
